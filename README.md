# Grupo M2 — Landing Page

Institutional landing page developed for Grupo M2, a company focused on scaling sales through strategy, management, and performance in marketplaces.

# 🛠️ Tech Stack
React
TypeScript
React Router DOM
React Hook Form + Zod
EmailJS (form handling)
Framer Motion (animations)
TailwindCSS
Embla Carousel
Lucide Icons / React Icons
TSParticles


# 🎨 Key Features
✅ Fully responsive landing page
✅ Smooth animations with Framer Motion
✅ Functional contact form with validation
✅ Email integration via EmailJS
✅ Clean and scalable component structure
✅ Modern UI focused on conversion
✅ Strong typography and layout for brand authority

# 📌 About the Project

Grupo M2 was created to turn digital presence into real, measurable results.

This landing page was built with a strong focus on:
Lead conversion
Clear value proposition
Modern user experience
Performance and responsiveness


# 🧠 Purpose
The goal of this project is to clearly communicate:

The brand positioning
The services offered
A value proposition based on sustainable growth
A simple and effective lead generation flow
